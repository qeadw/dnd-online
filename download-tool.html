Image Download Tool

How to use:

1. Paste an image URL and set a filename

2. Click "Preview" to check the image loads

3. Click "Add to Queue" to queue it for download

4. When ready, click "Download All" — each image will save via your browser's download dialog

5. Save them to: assets/races/ in the dnd-online folder

Batch mode: Paste multiple lines in format: filename.png|https://url.com/image.png
